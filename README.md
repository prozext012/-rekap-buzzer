# 📈 Rekap Buzzer Sosmed (PWA)

Aplikasi pencatat penghasilan harian khusus untuk *Freelance Buzzer Social Media*. Didesain khusus untuk tampilan *mobile* (*Mobile-First*) dengan antarmuka bertema *Vintage* yang elegan, padat, dan profesional. 

Aplikasi ini sepenuhnya mendukung **Progressive Web App (PWA)** sehingga dapat diinstal langsung menjadi aplikasi Android/iOS asli di *smartphone* Anda tanpa memerlukan Play Store atau App Store.

## ✨ Fitur Utama
- **Penghitungan Otomatis:** Akumulasi *Income* dan Saldo berjalan secara instan.
- **Dukungan Offline:** Karena data disimpan di `LocalStorage` peramban Anda, aplikasi ini 100% berfungsi tanpa koneksi internet.
- **True App Install (PWA):** Dapat ditambahkan ke layar beranda (Homescreen) sebagai APK mandiri tanpa *badge browser* (mendukung WebAPK).
- **Edit & Hapus Data:** Manajemen data yang mudah dengan modal *custom* yang intuitif dan *smooth*.
- **Animasi Halus:** Transisi perpindahan halaman *fade & scale* yang responsif tanpa membuat pusing.

## 🚀 Cara Instalasi & Penggunaan

1. Buka *link deployment* Vercel proyek ini melalui Chrome (Android) atau Safari (iOS).
2. Tunggu beberapa detik, lalu klik pilihan **Install App** / **Tambahkan ke Layar Utama** (*Add to Homescreen*) yang muncul.
3. Buka aplikasi dari daftar menu HP Anda.
4. Data siap diisi dan direkap dengan aman di memori lokal HP Anda!

## 📂 Struktur Folder (Deployment)
- `index.html` - Antarmuka dan logika sistem.
- `manifest.json` - Identitas PWA aplikasi.
- `sw.js` - Service Worker pembantu agar lulus uji aplikasi (PWA).
- `icon-192.png` & `icon-512.png` - Ikon aplikasi.
